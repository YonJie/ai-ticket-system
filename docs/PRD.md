# 产品需求文档（PRD）

## 1. 产品概述

**产品名称**：AI 智能客服工单系统  

**目标**：为客户提供在线提单与跟踪能力，为客服/管理员提供处理、指派与统计能力；创建工单时由规则引擎自动分类并生成默认 AI 建议回复，降低人工分流成本。

**技术边界**：Vue3 前端 + Spring Boot 2.x 后端 + Neon Postgres；前后端部署于 Vercel（后端 Docker）。

## 2. 用户角色

| 角色 | 枚举值 | 核心能力 |
|------|--------|----------|
| 客户 | `CUSTOMER` | 注册/登录、提交工单、查看自己的工单、留言、对已解决工单评价 |
| 客服 | `AGENT` | 登录、查看全部工单、筛选状态、改状态/指派、留言 |
| 管理员 | `ADMIN` | 客服全部能力 + 查看每日工单统计 |

演示账号（启动时由 `DataInitializer` 幂等写入，密码均为 `123456`）：`customer` / `agent` / `admin`。

## 3. 功能范围

### 3.1 认证

- 注册：用户名唯一；密码 BCrypt 存储；角色可选，默认客户
- 登录：校验密码，签发 JWT（默认 24h）
- 当前用户：`GET /api/auth/me`（需鉴权）

### 3.2 客户侧工单

- 新建工单（标题 + 描述）→ 服务端自动分类 + 写入 AI 建议回复，初始状态 `PENDING`
- 我的工单列表（分页，创建时间倒序）
- 工单详情：基本信息、留言时间线、评价（如有）
- 追加留言；若工单为 `RESOLVED`/`CLOSED`，留言后改回 `PENDING`
- 对 `RESOLVED` 工单提交一次评价（1–5 分 + 可选备注）

### 3.3 客服 / 管理侧

- 全部工单列表，支持按 `status` 筛选与分页
- 更新状态：`PENDING` → `PROCESSING` → `RESOLVED` → `CLOSED`（可按业务选择目标状态）
- 指派处理人（须为 `AGENT`/`ADMIN`）
- 留言（不改变工单状态）
- 更新使用 `updatedAt` 乐观锁，冲突返回 409

### 3.4 统计（仅管理员）

- `GET /api/stats/daily`：今日新增工单数 + 全库各状态计数

### 3.5 非功能

- 统一 API 响应：`{ success, data, message?, code? }`
- 除白名单外接口需 JWT
- 健康检查：`GET /api/health` → `{ "status": "UP" }`

## 4. 业务规则摘要

### 4.1 自动分类

按标题 + 描述文本匹配（优先级从上到下）：

1. 含「退货」或「退款」→ `退货`
2. 含「物流」或「快递」→ `物流`
3. 含「账户」或「登录」→ `账户`
4. 其他 → `其他`

默认 AI 建议回复：`感谢您的反馈，我们已收到工单，预计 24 小时内处理。`

细则见 [AI_PROMPTS.md](./AI_PROMPTS.md)。

### 4.2 评价

- 仅客户、仅本人工单、仅 `RESOLVED`、每单仅一次

### 4.3 权限一览

| 操作 | CUSTOMER | AGENT | ADMIN |
|------|----------|-------|-------|
| 创建工单 | ✓ | ✗ | ✗ |
| 看自己的工单 | ✓ | — | — |
| 看全部工单 | ✗ | ✓ | ✓ |
| 改状态 / 指派 | ✗ | ✓ | ✓ |
| 留言 | 自己的 | 任意 | 任意 |
| 评价 | 自己的且已解决 | ✗ | ✗ |
| 每日统计 | ✗ | ✗ | ✓ |

## 5. 前端页面与路由

| 路径 | 角色 | 说明 |
|------|------|------|
| `/login` `/register` | 游客 | 登录 / 注册 |
| `/tickets` `/tickets/new` `/tickets/:id` | 客户 | 列表 / 新建 / 详情 |
| `/agent` `/agent/tickets/:id` | 客服、管理员 | 工作台 / 详情 |

未登录访问受保护路由 → 跳转登录；角色不匹配 → 跳转各自首页。

## 6. 验收要点

1. 三角色可登录，客户可创建带正确分类的工单
2. 客服可改状态与留言；客户对已解决工单可评价一次
3. 管理员可打开每日统计
4. 无 token / 错误 token 访问受保护接口返回 401
5. 前后端同域部署后 `/api/health` 与登录链路可用

## 7. 明确不做（当前版本）

- 真实大模型对话 / RAG（仅规则分类 + 固定建议回复）
- 文件附件上传
- 邮件 / 站内通知推送
- 细粒度 RBAC 与操作审计日志
