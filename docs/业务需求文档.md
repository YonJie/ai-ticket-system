## 1 概况

### 1.1 需求描述

为客户提供在线提单、跟踪、留言与评价能力；为客服/管理员提供工单处理、状态变更、指派与留言能力。创建工单时由 DeepSeek（或规则回退）自动分类并生成 AI 建议回复，降低人工分流成本。

**范围说明**：本文档描述**当前已实现**能力，不包含附件、通知推送、多轮 AI 对话/RAG、细粒度 RBAC 与审计日志等扩展项。

**本期状态**：本期功能已实现并可演示/部署（Vue3 前端 + Spring Boot 后端 + Neon Postgres，部署于 Vercel）。

### 1.2 功能清单

| 序号 | 功能模块 | 功能说明 |
|------|---------|---------|
| 1 | 用户认证 | 注册、登录、当前用户信息；JWT 鉴权与按角色路由分流 |
| 2 | 客户工单 | 新建工单、我的列表、详情、追加留言、已解决评价 |
| 3 | 客服/管理工单台 | 全部工单列表与状态筛选、改状态、指派、留言、乐观锁冲突处理 |
| 4 | AI 辅助（分类与建议回复） | 创建工单时 DeepSeek 优先，失败/无 Key 时规则回退 |
| 5 | 管理员日统计 | 今日新增与各状态计数（仅 ADMIN；接口已实现） |

### 1.3 应用集成

| 模块 | 功能点 | 外部应用 | 交互说明 |
|------|-------|---------|---------|
| AI 辅助 | 分类 + 建议回复 | DeepSeek API | 创建工单时调用 `deepseek-v4-flash`（关 thinking）；无 Key/超时/非法输出则规则回退 |
| 全部业务 | 持久化 | Neon Postgres | 用户、工单、留言、评价数据存储；连接串为 JDBC 形式 `DATABASE_URL` |
| 部署 | 前后端同域 | Vercel | `/api/*` 路由到后端容器，其余为前端静态资源 |

### 1.4 需求计划

本期功能已实现上线/可演示，本文档用于现状对齐与评审，不另列排期表。

### 1.5 用户角色（概况）

| 角色 | 枚举值 | 核心能力 |
|------|--------|----------|
| 客户 | `CUSTOMER` | 注册/登录、提交工单、查看自己的工单、留言、对已解决工单评价 |
| 客服 | `AGENT` | 登录、查看全部工单、按状态筛选、改状态/指派、留言 |
| 管理员 | `ADMIN` | 客服全部能力 + 查看每日工单统计（接口） |

演示账号（启动时幂等初始化，密码均为 `123456`）：`customer` / `agent` / `admin`。

## 2 业务需求

### 2.1 用户认证

#### 2.1.1 功能设计及说明

| 项目 | 说明 |
|------|------|
| 角色 | 游客（注册/登录）；登录后任意角色可获取当前用户 |
| 功能简介 | 提供注册、登录与会话维持（JWT），并按角色进入对应首页 |
| 界面元素及控制说明 | 见下方详细说明 |

##### 登录界面（`/login`）

**表单区域：**

| 字段名 | 控件类型 | 必填 | 长度限制 | 联动规则 | 默认值 |
|--------|---------|------|---------|---------|--------|
| 用户名 | 输入 | 是 | — | — | 演示预填 `customer` |
| 密码 | 密码输入（可显示） | 是 | — | — | 演示预填 `123456` |

**按钮区域：**

- 登录：校验通过后调用登录接口，成功写入 token/用户信息，按角色跳转（客服/管理员 → `/agent`，客户 → `/tickets`；若存在 `redirect` 查询参数则优先跳转）
- 去注册：跳转 `/register`

##### 注册界面（`/register`）

| 字段名 | 控件类型 | 必填 | 长度限制 | 联动规则 | 默认值 |
|--------|---------|------|---------|---------|--------|
| 用户名 | 输入 | 是 | 2–64 字符，唯一 | — | 空 |
| 密码 | 密码输入（可显示） | 是 | 6–64 字符；服务端 BCrypt 存储 | — | 空 |
| 角色 | 下拉选择，选项「客户/客服」 | 是 | 对应 `CUSTOMER`/`AGENT` | — | `CUSTOMER` |

说明：接口侧角色可选且支持 `admin`（大小写不敏感），前端注册页当前仅开放客户/客服选项；管理员依赖演示账号或接口注册。

**按钮区域：**

- 注册：成功后自动登录并按角色跳转首页
- 去登录：跳转 `/login`

##### 业务逻辑说明

- 除白名单（`/api/health`、`/api/auth/register`、`/api/auth/login`）外，其余 `/api/**` 需 `Authorization: Bearer <token>`
- JWT 默认有效期 24 小时；无效/过期返回 401，前端清会话并引导重新登录
- 未登录访问受保护路由 → `/login`；角色不匹配 → 跳转各自首页
- 用户名已存在返回 400；用户名或密码错误返回 401

### 2.2 客户工单

#### 2.2.1 功能设计及说明

| 项目 | 说明 |
|------|------|
| 角色 | `CUSTOMER` |
| 功能简介 | 客户创建、查看、跟踪本人工单，并支持留言与已解决评价 |
| 界面元素及控制说明 | 见下方详细说明 |

##### 列表界面（`/tickets` 我的工单）

**查询区域：**

- 本期前端列表无独立查询条件；后端分页参数 `page`（默认 0）、`size`（默认 20，最大 100）

**列表区域：**

- 展示：标题、分类、状态、创建时间、操作（查看）
- 排序：创建时间倒序
- 分页：接口支持分页；前端当前按默认页加载列表

**按钮区域：**

- 新建工单：进入 `/tickets/new`
- 查看/标题链接：进入 `/tickets/:id`

##### 新建页面（`/tickets/new`）

| 字段名 | 控件类型 | 必填 | 长度限制 | 联动规则 | 默认值 |
|--------|---------|------|---------|---------|--------|
| 标题 | 输入 | 是 | 前端限制 200 字，展示字数 | — | 空 |
| 描述 | 文本域 | 是 | 非空 | — | 空 |

**按钮区域：**

- 返回：回到我的工单列表
- 提交：创建成功后跳转详情页；创建过程触发 AI 分类与建议回复（见 2.4）
- 未保存离开：标题或描述有内容时触发未保存离开守卫

**系统自动生成字段（创建后）：**

| 字段名 | 说明 |
|--------|------|
| 分类 `category` | DeepSeek 或规则回退生成：`退货` / `物流` / `账户` / `其他` |
| AI 建议回复 `aiSuggestedReply` | DeepSeek 或固定回退文案 |
| 状态 `status` | 初始 `PENDING` |
| 客户信息 | 取当前登录用户 |

##### 详情界面（`/tickets/:id`）

**展示区域：**

- 工单基本信息：标题、描述、分类、状态、指派情况、创建时间等
- AI 建议回复（只读展示，如有）
- 留言时间线：发送者、角色标识（客户/客服）、时间、内容；按时间升序
- 评价信息：若已评价则展示评分与备注

**留言区域：**

| 字段名 | 控件类型 | 必填 | 说明 |
|--------|---------|------|---------|
| 留言内容 | 文本域 | 是 | 非空；客户仅可对本人工单留言 |

**按钮区域：**

- 发送留言：提交后刷新时间线；若工单为 `RESOLVED`/`CLOSED`，留言后状态改回 `PENDING`
- 评价：仅当状态为 `RESOLVED` 且尚未评价时可见/可操作

##### 评价弹层/表单

| 字段名 | 控件类型 | 必填 | 长度限制 | 联动规则 | 默认值 |
|--------|---------|------|---------|---------|--------|
| 评分 | 评分控件（1–5） | 是 | 整数 1–5 | — | 5 |
| 评论 | 文本域 | 否 | — | — | 空 |

**按钮区域：**

- 提交评价：每单仅一次；成功后展示评价结果，不可重复提交

##### 业务逻辑说明

- 客户仅能访问本人创建的工单；越权返回 403
- 仅客户可创建工单；客服/管理员创建返回 403
- 评价：仅本人工单、仅 `RESOLVED`、每单一次（`ticket_id` 唯一）
- 客户可通过留言接口或更新接口的 `extraMessage` 追加留言（前端详情页走留言接口）

### 2.3 客服/管理工单台

#### 2.3.1 功能设计及说明

| 项目 | 说明 |
|------|------|
| 角色 | `AGENT`、`ADMIN` |
| 功能简介 | 查看全部工单，按状态筛选，变更状态/指派，并回复留言 |
| 界面元素及控制说明 | 见下方详细说明 |

##### 列表界面（`/agent` 客服后台）

**查询区域：**

- 状态：下拉选择，选项「待处理/处理中/已解决/已关闭」，可清空表示全部；精确匹配；非必填；同步到 URL `?status=`

**列表区域：**

- 展示：标题、客户、分类、状态、处理人（已指派/未指派）、创建时间、操作（处理）
- 排序：创建时间倒序
- 分页：接口默认 `page=0`、`size=20`（最大 100）

**按钮区域：**

- 处理/标题链接：进入 `/agent/tickets/:id`

##### 详情界面（`/agent/tickets/:id`）

**展示区域：**

- 工单基本信息、客户信息、分类、状态、指派情况、创建时间
- AI 建议回复（只读）+「填入回复框」快捷操作
- 客户评价（如有，只读）
- 留言时间线

**操作区域：**

| 字段名 | 控件类型 | 必填 | 说明 |
|--------|---------|------|------|
| 修改状态 | 下拉选择，选项 `PENDING`/`PROCESSING`/`RESOLVED`/`CLOSED` | — | 变更即提交；关闭（`CLOSED`）需二次确认 |
| 回复内容 | 文本域 | 发送时必填 | 可一键填入 AI 建议回复 |

**按钮区域：**

- 填入回复框：将 `aiSuggestedReply` 写入回复输入框（无建议时禁用）
- 发送回复：调用留言接口；**不改变**工单状态
- 修改状态：调用更新接口；提交时携带客户端持有的 `updatedAt` 做乐观锁；若未指派，默认将 `assignedTo` 设为当前登录用户

##### 业务逻辑说明

- 客服/管理员可查看任意工单；可改 `status`、`assignedTo`
- 指派对象须为 `AGENT` 或 `ADMIN`
- 状态可选目标：`PENDING` → `PROCESSING` → `RESOLVED` → `CLOSED`（业务上允许按需选择目标状态，非强制逐步）
- 乐观锁：请求体 `updatedAt` 须与库一致，冲突返回 **409**，提示刷新后重试
- 客服留言不改变工单状态；客户在已解决/已关闭工单留言会打回 `PENDING`

### 2.4 AI 辅助（分类与建议回复）

#### 2.4.1 功能设计及说明

| 项目 | 说明 |
|------|------|
| 角色 | 系统自动（客户创建工单时触发）；客服可在详情页查看并采用建议回复 |
| 功能简介 | 根据工单标题与描述自动生成分类与建议回复 |
| 界面元素及控制说明 | 无独立配置页；结果展示在工单详情 |

##### 触发与结果展示

- 触发时机：`POST /api/tickets` 创建成功路径内同步生成
- 客户详情 / 客服详情：展示 `category`、`aiSuggestedReply`
- 客服可将建议回复填入留言框后发送

##### 业务逻辑说明

**优先 DeepSeek**（配置 `DEEPSEEK_API_KEY`）：

- 模型：`deepseek-v4-flash`（关闭 thinking）
- 一次输出：`category`（仅允许 `退货` / `物流` / `账户` / `其他`）+ `suggestedReply`

**回退规则**（无 Key / 超时 / 非法 category / 空回复）：按标题+描述文本匹配，优先级从上到下：

1. 含「退货」或「退款」→ `退货`
2. 含「物流」或「快递」→ `物流`
3. 含「账户」或「登录」→ `账户`
4. 其他 → `其他`

回退默认建议回复：`感谢您的反馈，我们已收到工单，预计 24 小时内处理。`

提示词与参数细则见同目录 `AI_PROMPTS.md`。

### 2.5 管理员日统计

#### 2.5.1 功能设计及说明

| 项目 | 说明 |
|------|------|
| 角色 | `ADMIN` |
| 功能简介 | 查询当日新增工单数及全库各状态计数 |
| 界面元素及控制说明 | **后端接口已实现**；前端本期无独立统计页面 |

##### 接口能力（`GET /api/stats/daily`）

**返回字段：**

| 字段名 | 说明 |
|--------|------|
| date | 统计日期，`yyyy-MM-dd` |
| newTicketsToday | 今日新增工单数（`createdAt` 落在当天 `[00:00, 次日 00:00)`） |
| statusCounts.pending | 全库待处理数 |
| statusCounts.processing | 全库处理中数 |
| statusCounts.resolved | 全库已解决数 |
| statusCounts.closed | 全库已关闭数 |

##### 业务逻辑说明

- 仅管理员可访问；非管理员返回 403
- 未登录返回 401
- 数据来自真实 `tickets` 表聚合，非缓存假数据
